# hacker_screen

A fake "hacking in progress" screen for prank/demo purposes — matrix rain, a
scrolling exploit log, a live hex dump, and a progress bar that periodically
flashes ACCESS GRANTED-style banners with a glitch burst.

Built with [macroquad](https://github.com/not-fl3/macroquad).

## Run

```
cargo run --release
```

## Controls

- `SPACE` — force an immediate breach flash
- `ESC` — quit
